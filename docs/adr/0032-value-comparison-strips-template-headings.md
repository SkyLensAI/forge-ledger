# "同一个值"的判据要剥掉模板骨架：章节标题不是内容

## 问题

ADR-0027 的判据 3 写的是：**归一化后完全相同 = 不是冲突，是再确认**。
它靠"归一化后的字节相等"把正常的重复证据挡在队列外面。

问题出在"归一化"这个词上：它当初只折叠了空白与行尾，而**两侧的形状本来就不一样**。

- 资产那一侧：`## 当前状态\n\n两周一个版本。`。
  `## 当前状态` 是分类法强制的章节（`REQUIRED_SECTIONS.state = ["当前状态"]`），
  每一条 state 都带着它，它是模板的骨架。
- 候选那一侧：`两周一个版本。`。模型抽出来的是一句话，没有理由带标题。

于是"同一条事实被再说一遍"会**每一次都被判成内容不同**，也就每一次都进队列。
判据 3 在纸面上成立、在行为上失效——而它失效的方向恰好是最贵的那一边：
队列被正常的重复证据淹掉，人开始成批点过，
**真的矛盾就藏在那一堆真真假假的条目里**（`evals/regressions/0003` 是同一个形状：
把两种不同的情况当成一种，于是一条判据永久报假警）。

这个缺口一直到 Phase 5 的端到端用例能真正跑起来之后才暴露：
之前它被"schema 里还没有 `subject`"挡在前面，测试红在一个更早的地方
（见 `evals/regressions/0005`）。

## 考虑过的选项

1. **在候选那一侧补标题**（让抽取器把 `## 当前状态` 也吐出来）。
   这等于把"资产长什么样"写进提示词，而 R8 说的正是不要这么干：
   提示词不是强制。换一个抽取器、换一次措辞，它就会失效，
   而失效的表现是"队列里突然多出一批看起来合理的冲突"。
2. **在资产那一侧削掉标题**（把 `## 当前状态` 从正文里删掉，值就是一句话）。
   那会让 `REQUIRED_SECTIONS` 永远报红，或者逼着分类法放弃章节要求。
   骨架被删掉之后，人读资产时就失去了"这一段讲的是什么"的提示。
3. **比较时剥掉行首的 ATX 标题**（两侧对称地剥）。判据是**一条能指着说的语法规则**：
   `^\s{0,3}#{1,6}(\s|$)`。它不猜"这句话像不像标题"，所以它可以被人复核。
4. **改用语义比较或相似度阈值。** 那就把"是不是同一个值"变成一个可以拧松的数字，
   而拧松它的后果是**真的矛盾被当成再确认**——这个产品最贵的失败模式。
   选项 4 从来不是备选，写在这里是为了说明它为什么不是。

## 选定

**选 3。** `normalizeValue` 在折叠空白之前先剥掉行首的 ATX 标题行（`packages/core/src/conflict.ts`）。

三条理由：

1. **它是对称的。** 同一段文字，剥不剥标题，两侧得到的处理完全一样。
   任何"只在某一侧做"的归一化都会重新变成"谁抽出来的"决定"算不算同一个值"。
2. **它是可复核的。** 判据是一条正则，不是一次判断。人对着两条记录说
   "这两句是不是同一句话"时，得到的答案与代码一致。
3. **它没有把判据交给模型。** 这与 ADR-0027 的判据 4 是同一条纪律：
   模型只能追加候选，不能决定"什么算同一个值"。

## 后果

- **好**：判据 3 从"纸面成立"变成"行为成立"。再确认不会进队列，
  队列的信噪比由一条硬判据保着。
- **好**：这条修法顺带覆盖了所有类型（decision/rule 的正文同样带模板章节），
  不需要按类型写第二份判据。
- **代价**：正文里的三级以上标题（`### …`）也会被剥掉。
  于是一份"用 `###` 分小节写状态"的资产，它的值会比写作者以为的更扁平：
  `### A\n甲\n### B\n乙` 与 `### B\n乙\n### A\n甲` 会被判成同一个值。
- **残余风险**：把这条也做成语义判断（"只剥模板要求的那些章节"）会让判据与
  分类法耦合，而分类法要能独立演进。所以这里选了便宜的、粗糙的那一边，
  并把它记在这里——**残余风险要写出来，而不是等它被撞上**（ADR-0027 的同一个做法）。
- **回归**：`packages/core/test/conflict.test.ts` 里那条"标题不同、正文相同"的用例
  钉住这条判据；`evals/regressions/0005` 记这次是怎么被发现的。
