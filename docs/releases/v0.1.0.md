# Forge v0.1.0

**A local-first ledger for AI context: typed, provenance-backed assets that CI
keeps from rotting.**

- No account, no cloud, no API key.
- Byte-for-byte reproducible output.
- Every claim must resolve to a provenance span.

## What this release fixes

Most AI memory tools solve extraction. Forge treats the real failure mode —
**silent rot** — as the product:

- **No provenance, no asset.** Broken citations fail CI instead of becoming
  metadata warnings.
- **Model output cannot enter `assets/`.** Candidates land in `_inbox/`;
  promotion is human-triggered. `origin === "model"` is non-configurable.
- **Rot is visible.** `forge health` reports orphan pages, index drift, expired
  assertions, and silently superseded states. It never "fixes" itself into
  looking healthy.
- **Output is deterministic.** Two fresh vaults emit byte-identical bytes; no
  clock, randomness, locale, or newline drift.

## Try it

```bash
git clone https://github.com/SkyLensAI/forge-ledger
cd forge-ledger
pnpm install
pnpm demo
# open demo/index.html
```

Or open the generated demo: <https://skylensai.github.io/forge-ledger/>

## Known gaps (not hidden)

- The browser extension has no real-browser automated DOM test.
- `model-http.ts` has no real-endpoint test without an API key.
- Audit writes have no file lock and no rotation.
- Merge proposals are not yet a durable queue.
- Retrieval is lexical and misses paraphrases.
- Regression cases 0003/0004 are not executable yet.
- Team edition is intentionally not started (`payment_signal: null`).

Full details: [`CHANGELOG.md`](../CHANGELOG.md).

## 中文

**把会话、文档、PR 编译成带类型、带出处的资产库——并由 CI 阻止它悄悄腐烂。**

- 无账号、无云端、无 API key。
- 逐字节可复现。
- 每条断言都必须解析到一个出处 span。

### 这一版修掉了哪种腐烂

- **没有出处就没有资产**：坏引用让 CI 变红，而不是变成“元数据小问题”。
- **模型产出不能进 `assets/`**：候选只进 `_inbox/`，晋升由人触发。
- **腐烂能被看见**：`forge health` 报孤立页、索引漂移、过期断言、静默被取代；
  它不会“自动修好”自己。
- **输出确定**：两个全新 vault 产出逐字节相同。

### 已知缺口（如实记账）

- 浏览器扩展没有真实浏览器里的自动化 DOM 测试。
- `model-http.ts` 没有真实端点测试。
- 审计没有文件锁、没有轮转。
- 归并提议还没有持久化成队列。
- 检索是词法的，会漏掉改写。
- 回归 0003/0004 仍不能自动执行。
- 团队版按设计未启动（`payment_signal: null`）。

完整说明见 [`CHANGELOG.md`](../CHANGELOG.md)。
